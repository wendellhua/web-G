## 1. 游戏概述

- **游戏名称**：《黑潮突围（VOID RUNNER）》
- **游戏类型**：纯前端无限大地图动作生存割草肉鸽（Survivors-like / Bullet Heaven）
- **运行平台与画幅**：PC 浏览器优先，**16:9 横屏**最佳体验（逻辑 `1280×720`，兼容窗口缩放与高分屏 DPR ≤ 2 清晰显示）
- **核心卖点**：
  1. **经典纯自动走位割草**：零门槛纯键盘走位，操作深度聚焦于走位拉扯、空间武器构筑与 Boss 斩杀节奏；
  2. **五阶段渐进式生涯推图（25+ 递增关卡）**：告别开局全解锁无区分度的扁平体验，按五大阶段逐步拉升单局时长（`3→5→7→9→11 分钟`）、Boss 数量（`1→2→2→3→4 只`）、敌怪梯度与技能槽位（`2+1 → 4+4`）；
  3. **单主角五形态自动觉醒**：累计通关达到 `3 / 8 / 16 / 25` 关自动解锁更高阶主角形态，获得**外观视觉进阶 + 技能卡槽解放 + 初始武器起始等级提升（Lv.1→Lv.5）**，形成鲜明阶段差异感；
  4. **低起点数值 × 天赋驱动**：所有形态共享低起点基础属性（移速 `150 px/s`、拾取范围 `100 px`），严格依靠局外 8 项永久天赋树逐步强化；
  5. **纯前端本地持久化与不可逆生涯**：全量进度保存于浏览器本地缓存，推进不可逆；提供带二次确认的「重置生涯」入口以回归第 1 关全新开荒。

### 2.2 关卡推进、难度递进与不可逆生涯规则
1. **单关递进机制**：玩家始终挑战当前最高未通关编号 `currentLevel`（起始为第 1 关）。每当成功通关当前关，进度自动推进至 `currentLevel + 1`（`clearedLevelsCount += 1`），并在本阶段基线之上按关内小阶索引（`subLevelIndex`）平滑微调敌怪生命、攻击与刷怪密度，确保同一阶段内每一关亦有清晰递进压迫感。
2. **严格不可逆进度**：不支持手动降级或回头重刷低关卡；挑战失败时进度严格停留在当前 `currentLevel`（不回退、不推进），同时**保留本局结算获得的虚空晶体**，形成“挑战当前关受挫 → 拿晶体点天赋变强 → 攻克当前关”的正反馈闭环。
3. **跨阶段自动形态解锁与公告**：当通关第 **3 / 8 / 16 / 25** 关（即累计通关数分别达到 `3 / 8 / 16 / 25`）时，系统自动解锁下一角色形态并同步晋级下一阶段；**胜利结算界面必须弹出醒目的「形态进阶解锁通知」**，明确告知玩家新解锁的形态名称、外观升级预览、新增技能槽位（如 `2+1 → 2+2`）以及初始武器起始等级提升（如 `Lv.1 → Lv.2`）。
4. **重置生涯（回到第 1 关）**：主界面提供「重置生涯 / 从头开始」按钮（必须经过明确二次弹窗确认）；确认后将彻底清除浏览器本地存档中的**角色形态、全部永久天赋、虚空晶体余额、关卡进度与历史战绩**，完全恢复为新玩家第 1 关初始状态（等同于清空浏览器缓存）。

### 2.3 多 Boss 登场、胜负判定与超时失败硬规则
1. **分时压轴登场**：各阶段 Boss 严格按上表时间轴每隔 2 分钟依次登场（前一只 Boss 未被击杀时，到点仍会按时间轴刷新下一只 Boss，形成高压同屏多 Boss 惩戒，倒逼玩家提升 DPS 及时清场）。
2. **Boss 击杀通关（可提前结算）**：当本关规定数量（`1 / 2 / 2 / 3 / 4` 只）的 Boss **全部被击杀**时，**立即触发胜利结算**并解锁下一关（无需干等到单局时间走完）。
3. **超时强制判败（Time-Up Defeat）**：当单局计时达到本阶段时间上限（`3 / 5 / 7 / 9 / 11` 分钟）时，若本关仍有任意 Boss 存活（或尚未全部击杀），**立即判定本局失败（超时未肃清 Boss）**；关卡进度保持在当前关卡不变，正常结算本局已获取的虚空晶体。
4. **血量归零判败**：任意时刻玩家生命归零立即判败，关卡进度保持当前关，正常结算晶体。
5. **同帧仲裁**：若在时间上限同一帧或玩家死亡同一帧击杀本关最后一只 Boss，优先判定**玩家险胜通关**（阶段 5 险胜且血量归零时隐藏继续无尽入口）。
6. **无尽黑潮（Endless Mode）归属**：仅在 **阶段 5（第 26 关起）** 击败全部 4 只 Boss 触发胜利结算时，提供「继续挑战无尽黑潮」入口；阶段 1~4 通关后聚焦快节奏推进下一关与形态解锁，不开启无尽模式。

## 3. 单主角五形态进阶体系（替代 V1 三角色晶体购买制）

### 3.1 形态定位与属性纪律
- **初始属性零偏移红线**：全部 5 个形态在进入关卡时共享完全一致的基础角色面板（由阶段 2 调优基线决定：最大生命 `100`、基础移速 `150 px/s`、经验拾取范围 `100 px`、基础暴击 `5%`），**形态本身不修改进入关卡的基础数值**，所有基础属性成长统一由局外 8 项永久天赋提供。
- **三大差异化维度**：
  1. **外观视觉进阶**：每个形态拥有独立的程序化几何机甲轮廓、装甲层数与能量核心光环升级（同时在资产清单预留独立 `FormVisualId`，供后续外部美术资源阶段无缝替换）；
  2. **技能卡槽解放**：严格按 `2+1 → 2+2 → 3+2 → 3+3 → 4+4` 逐阶开放；
  3. **初始武器起始等级递进**：每局开局固定装备初始基础主动武器**追踪脉冲枪（`tracking_pulse`）**，其开局自带等级随形态递增为 `Lv.1 → Lv.2 → Lv.3 → Lv.4 → Lv.5`（形态 V 开局即持 Lv.5 满级主武，拾取对应被动与精英箱后可极速体验首把超武觉醒）。

## 4. 操作与交互控制规范

保持经典**纯自动走位流**，无手动瞄准与主动冲刺：

- **角色移动**：`W / A / S / D` 或 `↑ / ↓ / ← / →` 八方向平滑移动（对角线速度归一化）。
- **武器释放**：全部已装备主动武器按冷却与空间索敌规则**全自动触发**。
- **升级三选一交互**：鼠标点击卡片，或快捷键 `1 / 2 / 3` 选择；按 `R` 消耗 1 次重随（Reroll）。
- **宝箱 / 祭坛 / 结算 / 解锁公告确认**：鼠标点击按钮，或按 `Space / Enter` 确认。
- **暂停与速查**：按 `Esc` 或 `P` 暂停/恢复；浏览器失焦/切后台强制自动暂停（弹窗之上进入 `PAUSED_OVER_MODAL` 保护原奖励）。

## 5. 核心系统规则清单

### 5.1 动态槽位上限与严格抽卡范围隔离规则（V2.0 重点强化）
- **开局初始配置**：每局开始固定占用主动槽位 #1 装备**追踪脉冲枪**（起始等级由当前角色形态决定：`Lv.1 ~ Lv.5`），其余主动槽与被动槽为空，等待局内升级构筑。
- **槽位上限读取自当前阶段**：本局可用主动槽位 `maxActiveSlots` 与被动槽位 `maxPassiveSlots` 严格读取当前阶段配置（`2+1 / 2+2 / 3+2 / 3+3 / 4+4`）。
- **严格抽卡边界（零超槽污染红线）**：
  1. **主动技能池**：当已装备主动武器数量 `< maxActiveSlots` 时，升级池允许抽取「未拥有新主动武器」与「未满级已装备主动武器」；**一旦已装备主动武器数量达到 `maxActiveSlots`（例如阶段 1 选满 2 把后），抽卡池必须 100% 剔除全部未拥有主动武器**，绝不允许出现玩家无法装备的新武器选项。
  2. **被动技能池**：当已装备被动核心数量 `< maxPassiveSlots` 时，升级池允许抽取「未拥有新被动核心」与「未满级已装备被动核心」；**一旦已装备被动核心数量达到 `maxPassiveSlots`（例如阶段 1 选满 1 个后），抽卡池必须 100% 剔除全部未拥有被动核心**，绝不允许出现玩家无法装备的新被动选项。
  3. **不足 3 张时的优雅补位**：当已选定的全部主动与被动技能均接近满级，导致合法升级/进化候选不足 3 张时，空缺卡位依次由 3 张固定保底强化卡补齐（`应急修复 +30% HP` / `虚空提炼 +40 晶体` / `过载增幅 +5% 全局伤害`），保证每次升级均稳定呈现 3 张 100% 可立即生效的合法选项。
- **重随规则**：每局默认赠送 **2 次免费重随**（受局外「命运重构」天赋加成）。

### 5.2 超武进化（Evolution）规则
- **解锁条件**：同时持有 `指定主动武器（满级 Lv.5）` + `对应配对被动核心（≥ Lv.1）`（即便是阶段 1 的 `2+1` 槽位，只要玩家合理搭配 1 把主武配对的被动，同样可以达成 1 把超武觉醒；阶段 5 的 `4+4` 最多可达成 4 把超武）。
- **触发途径**：精英宝箱 100% 优先触发就绪超武；普通升级池保留 **15% 低概率保底**（仅限玩家已装备且满足条件的主动武器，严禁越池抽取未拥有超武）。
- **形态 V 特殊爽感**：形态 V 开局即自带 `Lv.5` 追踪脉冲枪，只要在局内抽到配对被动「超频芯片」，即可立即激活「星穹集束炮」的进化资格。

### 5.3 无限地图与三大动态地图事件
无物理障碍物无限星域，边缘方向箭头（带距离数值）指引探索：
1. **充能祭坛（蓝色箭头）**：阶段 2 起开放；站圈充能 5 秒（离圈缓慢衰减 + 围堵刷怪），满进度释放全屏震退冲击波 + 三选一赐福；Boss 在场期间暂停刷新新祭坛（场上已有祭坛保留）。
2. **精英突袭（红色箭头）**：阶段 2 起按波次定时刷出精英怪，击杀必掉进化宝箱与高额经验/晶体；阶段 1 虽无精英突袭，仍可通过升级池 15% 保底机制触发超武进化。
3. **战术信标（青色箭头）**：全阶段开放（阶段 1 即有）；包含**全域磁核 / 虚空震爆 / 修复矩阵** 3 类即时触碰装置。

### 5.4 局外永久成长、经济与纯前端缓存规则
- **虚空晶体结算**：综合计算 `存活时间 + 击杀数 + 击杀 Boss/精英数 + 完成祭坛数 + 局内拾取晶体 + 通关阶段奖励加成`，并受「晶体萃取」天赋倍率放大；无论通关还是超时/阵亡失败均正常落盘发放。
- **8 项永久天赋树（支持一键免费洗点 100% 退还）**：
  1. `虚空甲壳`（最大生命，5 级）
  2. `跃迁引擎`（基础移速，5 级，每级 +6%，满级 `150 → 195 px/s`）
  3. `能量过载`（全局攻击力，5 级）
  4. `相位冷却`（冷却缩减，5 级）
  5. `引力视界`（经验拾取范围，5 级，每级 +16%，满级 `100 → 180 px`）
  6. `智识汲取`（经验倍率，5 级）
  7. `命运重构`（初始重随次数，3 级）
  8. `晶体萃取`（虚空晶体收益倍率，5 级）
- **纯前端本地持久化**：全部生涯进度（`currentLevel`、`clearedLevelsCount`、`unlockedFormId`、天赋等级、虚空晶体、战绩、设置）仅存于当前浏览器 `localStorage`（带 Schema 版本迁移、损坏容错与无痕模式 `memory_fallback` 降级，绝不白屏）。

## 7. 明确不做清单（Non-Goals · 严格范围红线）

1. **不做**后端服务器、账号云存档、联机合作或在线排行榜（100% 纯前端浏览器缓存）；
