## 1. 验证结论总览

通过可玩灰盒原型（`prototype/index.html`）实机试玩与实时调参，**《黑潮突围》的核心 30~60 秒玩法循环已验证成立**：

1. **纯自动走位割草手感成立**：`WASD` / 方向键八方向归一化移动 + 全自动多形态武器组合（远程锁敌脉冲 + 近身环绕相位刃 + 范围震荡波），在无手动瞄准与无冲刺的前提下依然具备清晰的走位拉扯乐趣。
2. **视听与打击感反馈成立**：受击闪白、适度击退（`195 px/s`）、屏幕微震、暴击高亮飘字与经验宝石**五声音阶递增合成音效**形成明确的多巴胺正反馈；深空暗蓝背景下的「我方青蓝 vs 敌方猩红/品红」阵营色相隔离可读性极佳。
3. **动态地图事件机制成立**：充能祭坛（边缘蓝箭头指引 + 站圈 5 秒读条 + 出圈缓慢衰减 + 压力刷怪 + 完成全屏震退与赐福抉择）能有效打破原地绕圈挂机，带来明确的风险收益博弈。
4. **空间网格与性能基线成立**：使用轻量化空间网格处理敌怪间软分离与子弹碰撞，在 200+ 同屏敌怪下仍保持流畅 60FPS，验证了后续正式版采用空间哈希网格（Spatial Hash Grid）的技术路线完全可行。

## 2. 试玩关键洞察：初始克制原则与成长空间预留

本次试玩沉淀出一条**至关重要的数值架构原则**（将直接指导阶段 5 静态配置表与局外天赋树设计）：

> **【初始能力克制原则】**：零局外天赋、局内 Lv.1 开局时，角色的基础移动速度与经验拾取半径**不应过高**，应保持"可操作但略带紧迫感"的基线；把"步履轻盈、大范围狂吸宝石"的极致爽感作为**局外永久天赋树（`跃迁引擎` / `引力视界`）与局内被动核心（`跃迁推进器`）的核心成长红利**，显著放大局外养成正反馈与"再来一局"驱动力。

由此推导出正式架构与阶段 5 数值设计必须遵守的 **3 条硬约束**：

1. **敌怪移速相对比例约束（防零天赋新手被无解追死）**：
   - 当玩家初始基础移速下调至 `150 px/s` 后，常规怪基础移速保持 `92 px/s`（玩家/常规怪 ≈ `1.63x`，走位空间健康）；
   - 高移速类普通怪（`疾影猎手 Runner`）在正式配置表中其初始移速倍率**必须控制在 `<= 1.42x`（约 `130 px/s`）以内**，确保零天赋开局玩家直线撤退仍略快于高速怪，不会出现无解必中扣血；
   - 仅允许**带地面红线预警的冲锋技能**（如精英怪「猩红先锋」与终局 Boss 冲锋）瞬时超过玩家移速，用"提前预警 + 垂直侧移躲避"取代单纯拼移速。
2. **开局射速补偿**：
   - 玩家初始移速降低后，将初始主力武器「追踪脉冲枪」的基础冷却从 `480 ms` 微微提速至 **`420 ms`**，保证前期清怪节奏利落不拖沓。
3. **同屏实体分级预算**：
   - 灰盒验证 `240` 同屏敌怪已具备很强的怪潮压迫感；正式版（阶段 4/5）采用对象池 + 空间哈希网格后，常规波次软上限对齐 `240`，后期终局怪潮与无尽模式硬上限可设定为 `300~320`（配合视野外经验宝石自动聚合成高阶金宝石）。

## 3. 锁定的阶段 2 基础手感参数基线（带物理单位）

以下参数为试玩实测锁定的**零天赋、初始角色基准（V-01 巡航者 Lv.1）**，阶段 5 编写静态配置表时必须以此为初始锚点：

| 参数标识（Config Key 参考） | 锁定基线值 | 物理单位 | 较初始默认调整 | 后续成长预留区间（局外满级 + 局内被动参考） |
| :--- | :---: | :--- | :--- | :--- |
| `playerBaseMoveSpeedPxPerSec` | **150** | `px/s` | `220 → 150`（下调留成长空间） | 局外满级约 `195~210 px/s`；叠加局内被动可达 `240~270 px/s` |
| `enemyBaseMoveSpeedPxPerSec` | **92** | `px/s` | 保持默认 | 随波次/无尽按安全非线性曲线微调，设硬上限 |
| `waveSpawnRateScale` | **1.0** | `ratio` | 保持默认 | 按 12 分钟波次导演时间线分阶段递增 |
| `pulseBaseCooldownMs` | **420** | `ms` | `480 → 420`（提速优化前期手感） | 配合冷却缩减最低钳制在安全下限（如 `>= 120 ms`） |
| `baseKnockbackPxPerSec` | **195** | `px/s` | 保持默认 | 结合敌怪抗击退系数 `knockbackResistanceRatio` 计算 |
| `playerBasePickupRadiusPx` | **100** | `px` | `115 → 100`（下调留成长空间） | 局外「引力视界」满级约 `160~180 px`；叠加磁核信标全图吸取 |
| `activeEnemySoftCap` | **240** | `count` | 保持默认 | 正式版常规波次 `240`，终局/无尽硬上限 `300~320` |
