## 1. V1.0 → V2.0 跨文档变更追踪矩阵

| 变更项 | V1.0 旧规格 | V2.0 新冻结规格 | 受影响文档与代码层 |
| :--- | :--- | :--- | :--- |
| **关卡与时长结构** | 单一 12 分钟模式 | **五大阶段 × 25+ 递增关卡**，单局时长上限 `3 / 5 / 7 / 9 / 11` 分钟 | `01` / `03` / `05` / `schemas` / L1 / L2 / L4 |
| **角色体系** | 3 角色晶体购买（带属性差异） | **单主角五形态自动解锁**（累计通关 `3/8/16/25` 关），基础属性全一致（仅受天赋影响），差异化为**外观 + 槽位 + 开局主武等级（Lv.1→Lv.5）** | `01` / `03` / `05` / `06` / `schemas` / L1~L4 |
| **技能槽位与抽卡** | 固定 `4+4` | 随形态解放 **`2+1 → 2+2 → 3+2 → 3+3 → 4+4`**；满槽后 100% 剔除未拥有技能，杜绝超槽抽卡 | `01` / `03` / `05` / L2 (`ProgressionSystem`) / L4 |
| **Boss 与胜负判定** | 第 12:00 单 Boss | Boss 数量 **`1 / 2 / 2 / 3 / 4`**，每 2 分钟压轴登场；击杀全 Boss 立即通关解锁下一关；**超时未全杀判败且进度保持当前关**；仅阶段 5 通关可进无尽 | `01` / `03` / `05` / `06` / L2 (`SimulationWorld`) / L4 |
| **本地缓存与重置** | `SaveDataV1` | 升级 **`SaveDataV2`（兼容 V1 自动迁移）**，纯浏览器缓存不可逆进度 + **带二次确认的重置生涯**回归第 1 关新玩家态 | `01` / `03` / `05` / `06` / `schemas` / L1 / L4 |

## 2. V2.0 分层改造与质量验收计划

1. **L1（契约、静态配置、存档 V2 与局外生涯）**：更新 `schemas/*.ts`、`src/assets/manifest.ts`、`src/config/gameConfig.ts`、`src/storage/SaveManager.ts`、`src/meta/MetaProgression.ts` 及 L1 单测（含 V1→V2 迁移、3/8/16/25 解锁边界与重置生涯测试）。
2. **L2（无头核心引擎与总控）**：更新 `gameContracts.ts`、`StatCalculator.ts`、`EconomyCalculator.ts`、`ProgressionSystem.ts`（动态槽位硬隔离）、`SimulationWorld.ts`（多 Boss 2 分钟时间轴、超时判败、形态起始等级）与 `GameController.ts`（推进下一关、产出形态解锁公告、重置生涯）及 L2 单测。
3. **L3 & L4（五形态视觉、UI 与测试桥）**：更新 `CanvasRenderer.ts`（5 形态逐阶外观）、`UiOverlayManager.ts` & `styles.css`（当前关卡/形态进度条、形态图鉴、二次确认重置生涯、倒计时/Boss 进度/锁态槽位 HUD、形态解锁通知横幅、超时失败提示）及 `main.ts`。
4. **阶段 9（全自动回归与报告更新）**：更新 `tests/simulation/`（验证全 5 阶段、动态槽位零超抽、多 Boss 击杀/超时判败）与 `tests/e2e/`（Chrome 真实浏览器全链路零报错），更新 `docs/08.质量验收与调优报告.md`。
