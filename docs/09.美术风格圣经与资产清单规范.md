## 1. 世界观视觉基调与「双阵营极致反差」法则

《黑潮突围》是一款俯视角、同屏最高 320 敌怪的高速生存割草游戏。为了让电影级华丽光影下依然拥有**毫秒级战局辨识度**，我们在造型语言、材质质感与色彩域三个维度建立严格的**「双阵营对立铁律」**：

| 视觉维度 | 我方阵营（人类尖端星舰 / 机甲） | 敌方阵营（虚空黑潮异虫 / 织主） | 背景环境（五大深空星域） |
| :--- | :--- | :--- | :--- |
| **造型语言** | **硬表面几何（Hard-Surface）**：对称精密装甲板、锋利倒角、矢量翼片、涡轮喷口、规则同心能量环 | **有机异形（Biomechanical Organic）**：非对称曲线甲壳、锋锐骨刺与节肢镰刀、多眼节/螯钳、脉动腐化腺体与触须 | 大尺度低频云雾星云、微弱战术坐标经纬网、远景漂浮星尘与裂隙裂缝 |
| **材质质感** | 钛银/曜石冷金属装甲 + 精密刻线（Panel Lines）+ 玻璃舱盖高光 + 纯净等离子辉光 | 暗红/紫黑生物几丁质硬壳 + 粘稠发光体液纹路 + 锯齿角质边刺 + 不稳定裂变核 | 低饱和哑光深空（明度严格锁在 `6% ~ 16%`），永不与前景抢戏 |
| **主色域** | 冷色调高纯发光：**星穹青 `#38BDF8`**、**钛银白 `#E2E8F0`**；高阶形态与超武升维至**电光金 `#FACC15`** | 暖/邪色调高对比：**猩红 `#F43F5E`**、**暗血甲壳 `#4C0519`**、**腐化紫 `#A855F7`**、**熔核橙 `#FB923C`** | 随五大阶段逐阶演变的深空冷暗底色（深靛 → 脉冲蓝 → 翠裂青 → 星轨紫 → 猩红深渊） |
| **动态生命感** | 引擎离子尾焰呼吸脉冲、护翼/星环匀速旋转、受击护盾波纹 | 节肢摆动/呼吸膨胀感、自爆虫红光蓄能膨胀、Boss 三阶段裂甲变色 | 双层视差星尘（远景 `0.15×` + 中景 `0.45×` 相机位移）+ 星云缓动 |

## 2. 色彩系统与电影级光影分层规范

### 2.1 六级视觉深度层级（Z-Order）
1. **L0 深空星云背景层**：按阶段切换的径向深空星云（`RadialGradient` 软雾 + 双层视差星尘 + 极细 4% 透明度战术星图网格）。
2. **L1 地面交互与预警层**：充能祭坛法阵、Boss 冲锋红线 / 自爆预警圈、经验晶体（小蓝/中绿/大金发光菱晶）。
3. **L2 敌方黑潮层**：按 `normal → elite → boss` 排序渲染；每只异虫带有微弱底部暗影锚定空间感，受击时叠加纯白闪光层（`hitFlash`）。
4. **L3 主角机甲与近身武器层**：主角五形态机体 + 动态等离子尾焰 + 环绕相位刃 / 恒星绞肉环（始终高于普通怪层级，确保千军万马中 100% 一眼锁定自己）。
5. **L4 弹幕与电影级光效层**：使用 `globalCompositeOperation = 'lighter'` 叠加高频发光弹幕、落雷电弧、激光主炮与奇点震荡环（低配模式自动回退普通混合并削减 70% 粒子）。
6. **L5 战术反馈与 HUD 层**：暴击电光金飘字、`BOSS 免疫` 虹紫浮字、屏幕边缘方向指示箭头、Boss 三阶段血条与玻璃拟态 HUD。

## 4. 工程接入与 60FPS 性能保障方案（待样板确认后实施）

1. **强类型 `AssetManager` + 离屏位图缓存（Offscreen Canvas Rasterization）**：
   - 启动时通过 `Image` 并行异步加载 `public/assets/sprites/*.svg`，光栅化预渲染到 `@2x` 离屏 Canvas（如 `192×192` / `256×256`）并缓存；
   - **同时生成一套纯白受击剪影缓存（White Hit-Flash Cache）**：敌怪受击时无需在主循环实时跑耗时像素滤镜，直接绘制白色剪影叠加层，300 只异虫同时挨打依然稳锁 **60 FPS**；
   - **永不阻塞降级契约**：任意资源加载失败或尚未完成时，自动无缝回退现有程序化几何绘制，保证 100% 零白屏、零 404 崩溃。
2. **电影级光影分级开关**：
   - 默认开启电影级星云视差 + 辉光混合（`lighter`）+ 完整粒子；
   - 设置页勾选「低配护眼模式」后自动关闭星云动态层、切回普通混合并削减 70% 粒子。
